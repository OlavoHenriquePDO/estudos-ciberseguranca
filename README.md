# 🛡️ Laboratório e Estudos de Cibersegurança

Bem-vindo ao meu repositório de estudos práticos em **Cibersegurança e Redes**. Este espaço é dedicado a documentar minha evolução, anotações de laboratórios e conceitos fundamentais na área de segurança da informação (com foco atual em segurança, mantendo a versatilidade para o desenvolvimento no futuro).

---

## 📚 Tópicos de Estudo

1. **Redes de Computadores:**
   - Conceitos de TCP/IP, DNS e modelagem de redes.
   - Análise de tráfego e funcionamento de firewalls.

2. **Sistemas Operacionais (Linux):**
   - Comandos essenciais de terminal para administração e auditoria.
   - Permissões de arquivos e gerenciamento de usuários.

3. **Laboratórios Práticos:**
   - Resolução de desafios básicos em plataformas como *TryHackMe*.
   - Simulações de varredura de vulnerabilidades e testes de intrusão iniciais.

---

## 🛠️ Ferramentas Utilizadas
* Linux (Ubuntu / Kali Linux)
* Wireshark / Nmap (conceitos iniciais)
* Git e GitHub para versionamento de projetos
